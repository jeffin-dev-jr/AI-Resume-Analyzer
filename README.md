# AI Resume Analyzer

AI-powered Resume Analysis and Job Matching System developed using React, Node.js, Express.js, and MongoDB.

---

## Project Overview

This project is designed to simplify the recruitment process by analyzing resumes, extracting skills, and matching candidates with suitable job opportunities using AI-based analysis techniques.

The system helps improve candidate-job alignment and provides an efficient platform for resume screening and job recommendations.

---

## Features

- Resume Upload and Analysis
- Skill Extraction from Resume
- AI-based Job Matching
- Candidate Dashboard
- Responsive Frontend UI
- MongoDB Database Integration
- REST API Backend
- Real-time Data Handling

## Installation and Setup

### Clone Repository

```bash
git clone https://github.com/your-username/AI-Resume-Analyzer.git
```

### Backend Setup

```bash
cd backend
npm install
node server.js
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside backend folder and add:

```env
MONGO_URI=your_mongodb_connection
PORT=5000
JWT_SECRET=your_secret_key
```
